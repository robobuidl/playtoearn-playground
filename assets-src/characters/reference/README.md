# PlayToEarn mascot references (owner-supplied, 2026-09-24)

These are the owner's own characters. They may be used as heroes (or supporting characters) in any Playground game, in any pose.

| Character | Look | Reference files |
|-----------|------|-----------------|
| **Teddy** | Brown bear, blue hoodie, orange track pants with a stripe, blue sneakers, often gold-rimmed sunglasses. Friendly, expressive. | `teddy/teddy-waving.webp`, `teddy/teddy-excited.webp`, `teddy/teddy-shocked-sunglasses.webp`, `teddy/teddy-cool-hood-sunglasses.webp` |
| **Bull** | Muscular brown bull, cream horns, dark tank top, blue jeans, dark sneakers with grey soles. Ranges from confident to roaring to scared. | `bull/bull-confident-fists.webp`, `bull/bull-flexing-happy.webp`, `bull/bull-roaring-angry.webp`, `bull/bull-scared.webp` |
| **Dragonwhale** | Teal sea-dragon with a whale tail, golden segmented belly, golden horns and fins, yellow eyes, speckled scales. | `dragonwhale/dragonwhale-waving.webp` |

## Usage rules (owner decision D24)

1. **Never put the PlayToEarn logo, wordmark or any text on the characters' clothing.** The references show "PLAY TO EARN" and the logo on shirts and hoodies: every generated derivative must show plain clothing instead. This also follows the global no-text rule for generated images.
2. Clothes may change per game (for example a diving suit for an underwater game, a helmet for a runner), as long as the character stays recognizable.
3. Any pose and expression is allowed.
4. New characters (sidekicks, rivals, enemies) may be created in the same style universe.
5. Style to match: bold dark outlines (brown for Teddy and Bull, deep teal for Dragonwhale), glossy cel shading with soft gradients and white specular highlights, saturated colors, friendly cartoon proportions.

## Pipeline note

Before any game art is generated, build clean, logo-free, text-free model sheets for each character from these references (front, three-quarter, side and back views, plus key expressions). Use those clean sheets, never the raw references, as the references for game sprites and covers, so the logo cannot leak into outputs. Every output passes the no-text gate.
